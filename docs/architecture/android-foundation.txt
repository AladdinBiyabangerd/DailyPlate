ADR 001 — Android təməli (K01)
Qərar: 4 noyabr 2026

Platforma: istifadəçinin təsdiqi ilə ilk versiya Android; minimum Android 7.0
(API 24), compileSdk 36, targetSdk 36 (Android 16). iOS yalnız istifadəçi
Android nəticəsini bəyənib ayrıca davam qərarı verərsə hazırlanacaq.

Native Kotlin + Jetpack Compose seçildi: Android-first axın, sistem icazələri,
əlçatanlıq və lifecycle ilə birbaşa inteqrasiya. iOS üçün indidən əlavə skelet
və ya ortaq framework qurulmur; domain qaydaları UI və saxlama qatından ayrılacaq.

Toolchain: JDK 21 ilə Gradle 8.14.6, AGP 8.13.0, Kotlin/Compose compiler 2.1.10,
Compose BOM 2024.12.01, Activity Compose 1.13.0, test runner 1.7.0/JUnit ext 1.3.0. JVM bytecode 17-dir; Android runtime minimumu ayrıca 24-dür.
Versiyalar sabitlənib, dinamik dependency yoxdur; sonrakı update ayrıca yoxlanacaq.
SDK 36 konfiqurasiya istinadı: https://developer.android.com/about/versions/16/setup-sdk

K01 əhatəsi: bir app modulu, MainActivity giriş nöqtəsi, mövcud simple-* rənglərinin
Android resurs xəritəsi, minimal açılış səthi və instrumentation smoke testi.
Açılış səthi tam onboarding dizaynı deyil; düymə/naviqasiya/onboarding K06–K07-dədir.
Resurs mətnləri Azərbaycan dilindədir; üç dilin tam dəstəyi K06-da hazırlanacaq.
API 24–25 navigation bar-da dark-icon dəstəyi olmadıqda mövcud tünd mətn tokeni
scrim kimi istifadə edilir. Safe drawing insets mətnin sistem zolaqlarına düşməsini önləyir.
Dark palette olmadığı üçün light theme sabitdir; avtomatik rəng inversiyası edilmir.

Qovluqlar:
- android/app/src/main/java/az/qida/app: giriş və app koordinasiyası.
- ui/: yalnız render; ui/theme/: token xəritəsi və tema.
- K02-də model və repository sərhədləri, sonra feature üzrə paketlər əlavə ediləcək.
- android/tools/: təkrarlanan lokal yoxlamalar; src/androidTest/: cihaz testi.

Məlumat: K02-də user DB üçün Room seçilir; kitabxana ayrıca read-only mənbə olacaq.
K01-də hələ DB və ya şəbəkə yoxdur; mövcud 224 draft canlı tətbiqə import edilmir.
Uzaq backend/auth/store provider-i K25/K30 inteqrasiyasına qədər təxirə salınır.
Provider SDK-ları, server, API açarları və boş data layları indidən əlavə edilmir.
Backend seçimi auth-dan əvvəl ADR ilə həll olunmalıdır; foto server adaptor-u K23-dədir.

Yoxlama: real lint, Kotlin compilation, APK build və emulator/device-də Compose
launch/recreate instrumentation testi. Domen hesablaması olmadığı üçün saxta
unit test əlavə edilmir; domain testləri K02-dən başlayır. Min/target SDK APK
manifestindən də yoxlanır. Build API 24 cihaz sınağını əvəz etmir.
